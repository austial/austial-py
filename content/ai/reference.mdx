# Framework reference for agents

A dense, scannable summary of Austial's surface area, organised by the
question an agent actually has while coding. Each row links to the full page.
When this summary and a full page disagree, the full page wins.

## Request pipeline

```
middleware -> guards -> pipes -> interceptors (wrapping) -> handler -> exception filters
```

Guards run first, so unauthorised requests never pay for validation or reach
handler code. Exceptions raised anywhere in the pipeline, including FastAPI's
own validation errors, flow through the exception filters.

## Handler parameters

Python has no parameter decorators, so request data is bound with marker
defaults and type hints:

| You want | Write |
|---|---|
| JSON body validated by a DTO | `dto: CreateCatDto = Body()` |
| Path parameter | `id: int` (matches `:id` in the route) or `key: str = Param("key")` |
| Catch-all path (matches `/`) | route `files/:key*`, then `key: str = Param("key")` |
| Query string value | `limit: int = Query(default=10)` |
| Header | `x_request_id: str \| None = Headers("x-request-id")` |
| Parse a param/query value | `id: int = Param("id", ParseIntPipe)`, `page: int = Query("page", DefaultValuePipe(1), ParseIntPipe)` |
| Uploaded file | `file: UploadFile = UploadedFile("file", ParseFilePipe(...))` ([File upload](/techniques/file-upload)) |
| Client IP / host capture / session | `Ip()`, `HostParam("tenant")`, `Session()` |
| Your own marker | `create_param_decorator(lambda data, ctx: ...)` |
| Authenticated principal | `user=CurrentUser()` (`austial.auth`) |
| Tenant context | inject `TenantContext` in the constructor |
| Status code / header | `@HttpCode(204)`, `@Header("Cache-Control", "no-store")` |

## Errors

Raise these from anywhere; never build the response yourself. Every one takes
`(message: str | dict | None = None)`.

| Exception | Status | Exception | Status |
|---|---|---|---|
| `BadRequestException` | 400 | `ConflictException` | 409 |
| `UnauthorizedException` | 401 | `UnprocessableEntityException` | 422 |
| `ForbiddenException` | 403 | `TooManyRequestsException` | 429 |
| `NotFoundException` | 404 | `InternalServerErrorException` | 500 |
| `MethodNotAllowedException` | 405 | `ServiceUnavailableException` | 503 |
| `NotAcceptableException` | 406 | `BadGatewayException` | 502 |
| `RequestTimeoutException` | 408 | `GatewayTimeoutException` | 504 |
| `GoneException` | 410 | `NotImplementedException` | 501 |
| `PayloadTooLargeException` | 413 | `UnsupportedMediaTypeException` | 415 |

Response shape: `{"statusCode", "message", "error", "timestamp", "path"}`.

## Data access (`austial.orm`)

| Task | API |
|---|---|
| Define a table | `@Entity()` class with `PrimaryGeneratedColumn()`, `Column()`, relation markers |
| Wire the connection | `OrmModule.for_root(type_="postgres" \| "sqlite", url=..., entities=[...])` or `for_root_async(use_factory=..., inject=[ConfigService], entities=[...])` |
| Wire a feature's entities | `OrmModule.for_feature([Cat])` in the feature module |
| Get a repository | `repo: Repository[Cat] = InjectRepository(Cat)` |
| Read | `find`, `find_one`, `find_by`, `find_one_by`, `count` |
| Write | `save` (insert when PK unset, else update), `insert` (always insert), `update(criteria, partial)`, `delete(criteria)`, `remove(entity)` |
| Filter | `FindOptions(where=..., relations=[...], order_by=..., skip=, take=)`; wrap values in `In([...])`, `NotIn([...])`, `IsNull()`, `NotNull()` |
| Aggregate | `repo.sum(column, criteria=, group_by=)`, `repo.aggregate("SUM" \| "AVG" \| "MIN" \| "MAX", ...)` |
| Complex query | `repo.create_query_builder("alias")` with `.where(sql, params)`, `.where_eq`, `.where_in`, joins, `.get_many()` |
| Transaction | `await data_source.transaction(async_callback)` |
| Immutable rows | `@Entity(append_only=True)` (audit, ledger) |
| Initialise | `await app.get(DataSource).initialize()` at startup |

Relations (`OneToOne`, `OneToMany`, `ManyToOne`, `ManyToMany`) take a class or
a `lambda: Class` target, and pass `join_column=JoinColumn(...)` as a keyword
argument. Full detail: [Database](/techniques/database).

## Guard ordering

When stacking guards, list them in the order they must run:

```python
@UseGuards(AuthGuard, TenantGuard, RolesGuard)
```

`TenantGuard` and `RolesGuard` read the principal that `AuthGuard`
publishes on `request.state`, so `AuthGuard` must come first. Rate limiting
and idempotency guards usually go before `AuthGuard` so abusive traffic is
rejected cheaply.

## Known limits

Do not build on features that do not exist yet:

- `Scope.REQUEST` exists, but scope bubbles up: a controller, guard or provider that depends on a
  request-scoped provider (or the `REQUEST` token) is built per request. Prefer singletons.
- Module `imports` / `exports` are a visibility boundary only with
  `AustialFactory.create(AppModule, strict_modules=True)`; otherwise the container is flat.
  Write them correctly anyway.
- `CallHandler.handle()` is a plain async continuation, not an RxJS
  Observable.
- `DataSource.initialize()` is a manual step (a `startup` event handler). `OrmModule` does not
  initialise it for you; lifecycle hooks (`on_module_init`) run *after* startup handlers.
- No alternative HTTP platform. Microservice broker transports (Redis, NATS, Kafka, MQTT, RabbitMQ, gRPC) need their extra installed and only gRPC/Redis
  are tested against real clients; Redis Pub/Sub delivers to every replica. GraphQL is Strawberry code-first; WebSockets are plain
  frames unless `WebSocketsModule.for_root(adapter=SocketIoAdapter())` (client `join`/`leave` are `async`).
- `ExecutionContext.get_type()` is `"http"` in routes, `"ws"` in gateways and `"rpc"` in microservice handlers; the other `switch_to_*` raise.
- `austial.schedule` jobs run in every replica (use `austial.jobs` for once-only, durable work). MongoDB and Prisma are
  connection-level integrations, not ORMs. Verify OIDC ID tokens with `OAuth2Provider.verify_id_token` (never trust them unverified).
- `async` factory providers are awaited at init (`await app.init()` / ASGI startup / `compile()`); a plain sync
  `use_factory` runs when first resolved. Async factories must be singletons.
- Only PostgreSQL (`asyncpg`) and SQLite (`aiosqlite`) drivers exist.
- The `Tenanted` mixin's `tenant_id` is invisible to mypy's synthesised
  `__init__`. Declare the column on the entity directly if strict typing
  matters more than reuse.

## Gotchas that cost agents the most time

| Symptom | Cause | Fix |
|---|---|---|
| Route returns 404 / not in `/docs` | Controller or module not registered | Add to `controllers=[...]` and import the module from `AppModule` |
| `Cannot resolve` DI error | Provider missing from any module's `providers` | Register it; check the `__init__` type hints are real classes |
| `InjectRepository` fails to resolve | Entity not registered | `OrmModule.for_feature([Entity])` in the owning module, and the entity in `for_root(entities=[...])` |
| `save()` on a UUID-keyed row updates nothing | `save()` treats a set PK as an UPDATE | Use `insert()` |
| `where={"col": None}` matches nothing | Compiles to `= NULL` | Use `IsNull()` |
| App works with `python src/main.py`, tables missing under uvicorn | `bootstrap()` never runs under `uvicorn src.main:app` | Initialise `DataSource` in a `startup` event handler |
| Rate limit keyed on the proxy's IP | `X-Forwarded-For` ignored by default | Set `SecurityConfig.trusted_proxy_hops` |
| `CurrentUser()` is `None` on a protected route | No `AuthGuard` ran for that route | Add the guard, or register it globally |
