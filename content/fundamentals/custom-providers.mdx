# Custom Providers

A module's `providers=[...]` list accepts more than a plain `@Injectable()`
class — `useValue`/`useClass`/`useFactory`/`useExisting` shapes, expressed as plain dicts
(Austial has no decorators-only metaprogramming trick for this, so a dict
with a `"provide"` key is the literal provider definition).

## Value providers — `useValue`

Bind a token to a fixed, already-constructed value — handy for constants,
mocks, or third-party client instances:

```python
providers=[
    {"provide": "API_KEY", "useValue": "super-secret"},
]
```

```python
from austial import Inject


@Injectable()
class ExternalApiService:
    def __init__(self, api_key: str = Inject("API_KEY")):
        self._api_key = api_key
```

## Class providers — `useClass`

Bind a token to a class the container should instantiate (resolving *its*
constructor dependencies as usual) — useful for swapping implementations
per environment:

```python
providers=[
    {"provide": CacheService, "useClass": RedisCacheService},
]
```

Any consumer that type-hints `CacheService` receives a `RedisCacheService`
instance instead.

## Factory providers — `useFactory`

Bind a token to the return value of a function, optionally with its own
injected dependencies via `inject=[...]`:

```python
providers=[
    {
        "provide": "DATABASE_URL",
        "useFactory": lambda config: config.get("DATABASE_URL", "sqlite+aiosqlite:///./app.db"),
        "inject": [ConfigService],
    },
]
```

The factory function is called with each of `inject`'s tokens resolved and
passed positionally, in order — this is exactly how
`OrmModule.for_root_async(use_factory=, inject=)` and
`ConfigModule.for_root()` build their own providers under the hood (see
[Dynamic Modules](/fundamentals/dynamic-modules) and
[Database](/techniques/database)).

### Optional factory dependencies

An `inject` entry can be a dict to mark a dependency optional; it arrives as `None` when nothing is
registered under that token:

```python
{"provide": "MAILER", "useFactory": build_mailer, "inject": [ConfigService, {"token": "TRACER", "optional": True}]}
```

A factory may also set `"scope": Scope.TRANSIENT` to be called on every resolution instead of once.

## Async factory providers

A factory may be a coroutine function, for providers that need `await` to build — opening a connection,
fetching a secret, warming a client:

```python
async def connect(url: str) -> Database:
    db = Database(url)
    await db.connect()
    return db


providers=[
    {"provide": "DATABASE_URL", "useValue": "postgresql://localhost/app"},
    {"provide": Database, "useFactory": connect, "inject": ["DATABASE_URL"]},
]
```

Async providers are awaited **once, when the application initialises**, dependencies first, and cached as
singletons; afterwards `Database` injects like any other provider. That happens automatically under
`austial serve` / uvicorn (ASGI startup), `AustialFactory.create_application_context()` and
`await Test.create_testing_module(...).compile()`. If you build an app by hand, call `await app.init()`
before using it. Resolving an async provider earlier raises `AsyncProviderNotInitializedError` saying so.

An async factory must be a singleton (no `scope` other than the default), and its dependencies may
themselves be async providers or plain classes that depend on them.

## Alias providers — `useExisting`

Create a second name for a provider that already exists. Both tokens resolve to the **same instance**:

```python
providers=[
    LoggerService,
    {"provide": "AliasedLoggerService", "useExisting": LoggerService},
]
```

```python
assert app.get("AliasedLoggerService") is app.get(LoggerService)
```

It's the way to expose one implementation under both its concrete class and an abstract token without
building it twice. (`useClass` would create a second instance.)

## Optional dependencies in constructors

`X | None` in a constructor hint is unwrapped: Austial injects `X` when it can provide it, and otherwise passes
`None` (or the parameter's default):

```python
@Injectable()
class Mailer:
    def __init__(self, tracer: Tracer | None = None, retries: int = 3):
        ...
```

Builtin types (`str`, `int`, ...) are never built by the container. A parameter with a default value keeps
it unless its type is something the container provides, so `retries: int = 3` is `3`, not `0`.

## Non-class tokens

Any hashable value works as a `"provide"` token — a string (as above), or
a computed per-entity key:

```python
def repository_token(entity: type) -> str:
    return f"austial:orm:repository:{entity.__module__}.{entity.__qualname__}"
```

is precisely the pattern `austial.orm`'s `OrmModule.for_feature(...)` /
`InjectRepository(...)` use internally, so each entity gets its own
injectable `Repository` token without a shared string constant to collide on.
